# MD5：native(JNI) vs JCE（5 轮）

★ JMH 是 Mode.AverageTime ⇒ score 是 ns/op，**越大越慢**。
  比值 = jce 中位数 / native 中位数 ⇒ **>1 表示 native 更快**。
★ 跨 launch 取**中位数**（不取 min）—— 本机是开发机，min 等于挑运气。
★ 并发档（4t/16t）本机是超载 + 常驻外部负载 ⇒ **CV 大的格子不可外推**。
